# Maker Student

**Hardware, electronics, and makerspace resources for students** — KiCad, Arduino ecosystem, ethical kit vendors, and campus makerspaces. Practice safety; follow lab rules.

> **Disclaimer:** Equipment grants may live in [build-grants](https://github.com/Jay-Lokhande/build-grants); this repo is learning & community entry points.
